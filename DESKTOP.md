# Aplikacja desktop (Windows)

Kod aplikacji **Electron** nie jest w tym repozytorum — to repo dotyczy wyłącznie **rozszerzenia Chrome**.

Aplikacja Windows (notatki przypięte do `.exe`, ten sam UI):

**https://github.com/Sliskislimak/better-quick-notes-desktop**

Klonowanie i uruchomienie:

```powershell
git clone https://github.com/Sliskislimak/better-quick-notes-desktop.git
cd better-quick-notes-desktop
npm install
npm start
```
